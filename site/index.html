Then you spend an hour on the last 20%.

01

Point. Grab. Move.

Click to select, double-click to go deeper, drag to move. Where you drop it is where it goes.

02

Eight handles. Resize.

Every side and corner is a handle. The badge shows real pixels; the CSS stays in cqw or %.

03

Retype anything.

Double-click and type. Enter commits, Esc cancels, every keystroke is undoable.

04

Size type by eye.

Step it until it looks right. A fluid 5.4 cqw is still cqw when you're done.

05

One card, or all seven.

Seven cards share a selector. Hover All 7 to see the blast radius, or pick Only this — you always know which.

06

Every param, a real control.

Gradients, shadows, radius, fill, stroke, spacing — structured editors, not a CSS textarea.

07

Swap the artwork.

One button, your file picker, frame untouched. Works on <img> and CSS backgrounds alike.

08

Hide it. Judge the page.

Toolbar in the way? Click the mark — it shuts to just the logo, red when hidden. Your edits keep working.

Design rules

Four things it refuses to do.

  1. Look like AI made it. No purple gradients, no glass blur. Hairlines, hard colours, square corners.
  2. Rank its own controls. Peers are equal-width and always there. Unavailable ones grey out in place.
  3. Hide state. Saved or dirty, open or shut — always visible, never a convention you must learn.
  4. Touch the shipped page. Without ?edit=1 nothing loads at all.
Install

Two files. One loader.

Ask your agent to add it, or paste this yourself:

<!-- before </body> — loads only when the URL carries ?edit=1 -->
<script>
  if (location.search.indexOf("edit=1") !== -1) {
    var css = document.createElement("link");
    css.rel = "stylesheet";
    css.href = "tools/visual-editor.css?v=18";
    document.head.appendChild(css);
    var js = document.createElement("script");
    js.src = "tools/visual-editor.js?v=18";
    js.defer = true;
    document.body.appendChild(js);
  }
</script>
